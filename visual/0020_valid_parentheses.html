#20 Valid Parentheses

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

🔤 String 📚 Stack ⏱️ O(n)
📄 Python: python/0020_valid_parentheses/0020_valid_parentheses.py

🧠 How It Works (Layman's Terms)

Think of stacking plates (LIFO - Last In, First Out):

  • Opening bracket: Push it onto the stack (like adding a plate)
  • Closing bracket: Pop the top plate and check if it matches
  • Mismatch: Wrong plate on top → Invalid!
  • Empty stack when closing: Nothing to match → Invalid!
  • Non-empty stack at end: Unclosed brackets → Invalid!
